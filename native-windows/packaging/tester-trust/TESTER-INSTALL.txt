VEX VPN — Windows beta для одобренных тестировщиков

Скачивайте весь ZIP из раздела «Тестирование» личного кабинета VEX и извлеките
его в отдельную папку. Выберите x64 для обычного ПК или ARM64 для Windows ARM.
Не переносите Setup отдельно от остальных файлов.

При первой установке нужно явно доверить тестовому центру подписи VEX.
Его сертификат ограничен подписью кода и не подходит для сертификатов сайтов.
Это отдельный тестовый издатель, который Windows не считает публичным издателем.
Закрытого ключа в скачиваемых файлах нет.

1. Сверьте SHA-256 файла VEX-Tester-Root.cer с личным кабинетом и этой строкой:
   86e38cef04f8c768d8cf6ae3fd27347a16fd9620063c7835220d2a650202a461
   Проверить файл можно командой: certutil -hashfile VEX-Tester-Root.cer SHA256
2. Откройте VEX-Tester-Root.cer, выберите «Установить сертификат», «Локальный
   компьютер», затем вручную хранилище «Доверенные корневые центры сертификации».
   Подтвердите только центр «VEX VPN Tester Root 2026» после сверки отпечатка.
3. После настройки доверия проверьте подпись самого Setup. В PowerShell,
   открытом в распакованной папке, выберите файл своей архитектуры:

   $setup = '.\VEX.Setup.x64.exe'
   # Для ARM64 вместо x64 укажите arm64.
   $signature = Get-AuthenticodeSignature -LiteralPath $setup
   if ($signature.Status -ne 'Valid') { throw 'Подпись Setup не подтверждена' }
   $hash = [Security.Cryptography.SHA256]::Create()
   try { $pin = [BitConverter]::ToString($hash.ComputeHash($signature.SignerCertificate.RawData)).Replace('-', '').ToLowerInvariant() }
   finally { $hash.Dispose() }
   if ($pin -cne '6a4f3f238671b275a6f51f638d3852b55fc9dbd6b7acb4b703c492b00c0faf55') { throw 'Издатель Setup отличается от тестового издателя VEX' }
   Unblock-File -LiteralPath $setup

   Эта команда подтверждает доверие только проверенному Setup, скачанному
   из интернета. Она соответствует флажку «Разблокировать» в свойствах
   этого файла и не меняет настройки защиты Windows.
4. Запустите VEX.Setup.x64.exe или VEX.Setup.arm64.exe из той же папки.
   Установщик проверяет подписи, состав и хэши пакета перед установкой службы.
5. Войдите в одобренный аккаунт VEX. Бесплатный доступ действует в течение
   участия в программе. Проверяйте задания и отправляйте обратную связь
   в разделе «Тестирование» личного кабинета.

Следующие подписанные beta-обновления доступны через проверку обновлений VEX.
Отключать проверку подписей, антивирус или менять сетевые настройки не требуется.

После окончания тестирования удалите приложение обычным способом. Если больше
не используете тестовые приложения VEX, в certlm.msc можно удалить только
«VEX VPN Tester Root 2026» с указанным выше отпечатком. Не удаляйте другие центры.
